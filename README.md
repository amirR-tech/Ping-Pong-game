# 🏓 Ping Pong Game

A simple two-player Ping Pong game built with Pygame.

---

## ⚙️ Prerequisites
- Python 3.6 or higher
- Install Pygame:
```bash
pip install pygame
```

---

## 📥 Installation & Run
1. Download the `Game.py` file.
2. Run it in your terminal:
```bash
python Game.py
```

---

## 🎮 Controls
| Player | Keys |
|--------|------|
| 🔴 Red (Left) | `W` (Up), `S` (Down) |
| 🔵 Blue (Right) | `↑` (Up), `↓` (Down) |

- The first player to reach 10 points wins.
- After 5 points, the ball speed increases.
